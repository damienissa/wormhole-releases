# Wormhole for Mac

Remote access to your Mac, window by window: open an app running on your Mac mini
or Mac Studio as its own window on the Mac in front of you, or see its whole screen.
Direct, end-to-end encrypted, no account.

This repository holds the signed, notarized releases.
